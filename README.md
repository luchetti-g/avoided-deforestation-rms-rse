# Avoided deforestation in the Sorocaba Metropolitan Region (RMS), Brazil

Data supporting the article on the identification of areas eligible for REDD+ projects in the Sorocaba Metropolitan Region (São Paulo, Brazil), based on land use and land cover change modelling (MLP neural network, TerrSet Land Change Modeler) for 2003–2023 and projection to 2053.

## Contents

| File | Description |
|---|---|
| `project-area.tif` | REDD+ project area |
| `reference-area.shp` | Reference region |
| `leakage-area.shp` | Leakage belt |
| `transition-forest-all.tif` | Transition potential of forest loss |
| `landcov_predict_2053.tif` | Projected land use and land cover for 2053 |
| `gains-losses-23-53.tif` | Land cover gains and losses, 2023–2053 |
| `REDD-project-area.xlsx` | Area statistics |

Coordinate reference system: SIRGAS 2000 (EPSG:4674).

## Input data not included

Land use and land cover maps (2003, 2013, 2023) are from MapBiomas Collection 9. The driver variables (distances to urban areas, roads, power lines, water bodies and protected areas; elevation, slope and RUSLE) were derived from public datasets (IBGE, DataGEO/IDEA-SP, ANA, ANEEL and USGS), as described in the article.
